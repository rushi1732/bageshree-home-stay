## 🌿 Overview
An ultra-modern, high-end, responsive web application for **Bageshree Home Stay**, a nature retreat nestled amidst Alphonso mango and cashew nut orchards in Guhagar, Ratnagiri. Designed with an earthy Konkan luxury color palette (forest greens, warm cream/sand, sunlit gold accents), refined typography, and Lucide iconography.

## ✨ Key Features
- **Hero Slideshow**: Immersive full-screen background slider highlighting the orchard, rooms, and evening ambiance.
- **Accommodations Showcase**: Detailed room cards with amenity badges, multi-photo preview strip, and direct WhatsApp reservation links.
  - Deluxe AC Garden Room (Split AC, Inverter backup, ensuite geyser)
  - Executive Family AC Suite (Double Queen beds for 4-6 members)
  - Comfort Nature Breeze Room (Naturally cool, budget-friendly)
- **Amenities**: Homely Konkan breakfast & local meals, expansive compound parking for multiple SUVs, fairy-lit ambient evening lighting, mango/cashew orchard, 24/7 power backup, and high-speed Wi-Fi.
- **Interactive Photo Gallery**: Category-filtered masonry grid with full-screen Lightbox modal and keyboard navigation.
- **Guhagar Attractions Guide**: Distance, travel times, and highlights of Guhagar Beach, Vyadeshwar Temple, Velneshwar, Hedvi Beach, and Shringartali Bazaar.
- **Interactive Booking Inquiry & Price Calculator**: Real-time stay cost estimate that formats and transmits directly to the owner's WhatsApp (`+91 94038 34127`).
- **Location & Google Map**: Embedded map, copyable address, and direct Google Maps navigation button.
- **Quick Mobile Actions**: Persistent floating buttons for direct calling and WhatsApp chats.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React (Strict zero-emoji UI design)
- **Deployment**: Vercel-ready with `vercel.json`

## 🚀 Getting Started

### Local Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```

## 🌐 Deploying to Vercel
1. Push to GitHub (`main` branch).
2. Import project in [Vercel](https://vercel.com).
3. Framework Preset: `Vite`.
4. Output Directory: `dist`.
5. Deploy!
